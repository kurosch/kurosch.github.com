Mistral PR Reviewer.

An automated pull-request review agent powered by Mistral AI.

What is this?

Mistral Reviewer is a GitHub App that reviews open pull requests on Kurosch’s repositories. On every PR (opened or updated), a GitHub Actions workflow sends the diff and PR description to the Mistral API, which returns concise, actionable review feedback posted by the bot identity mistral-reviewer[bot].

How it works

PR opened → GitHub Actions workflow
→ exchange App key for installation token
→ send diff + context to Mistral API
→ post review as mistral-reviewer[bot] → human decides

Principles

  • Non-blocking: the bot posts comments only. It never approves, requests changes, or merges.
  • Focused: reviews flag real issues — bugs, security, performance, maintainability — not style noise.
  • Bounded: oversized diffs are skipped; stale runs are cancelled on force-push.
  • Scoped: the GitHub App has read-only content access and pull-request write permission, nothing more.
